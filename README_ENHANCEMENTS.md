## 📖 How to Use

### Step 1: Run a Scan
```
1. Go to Scanner
2. Enter IP, Domain, or Hash
3. Click "Scan"
4. Wait for results (8-15 seconds)
```

### Step 2: Review Results
```
1. View all findings organized by section
2. Check threat levels and severity
3. Review detailed information
```

### Step 3: Export to PDF
```
1. Click "Export to PDF" button
2. File downloads automatically
3. Filename: osint-report-[target]-[date].pdf
```

### Step 4: Share & Act
```
1. Open PDF in any reader
2. Review executive summary
3. Follow prioritized recommendations
4. Document remediation efforts
```

## 🆘 Need Help?

### Common Questions
**Q: What format is the PDF?**  
A: Professional A4 format suitable for printing and email

**Q: Can I customize the report?**  
A: Current version uses standard format; custom templates planned for Q2 2025

**Q: How long is the report?**  
A: Typically 3-8 pages depending on findings

**Q: Is all my data included?**  
A: Yes, 100% of scan results are in the PDF

**Q: How long does export take?**  
A: Less than 5 seconds

### Troubleshooting
**Export not working?**
- Clear browser cache
- Try different browser
- Ensure ad-blocker allows downloads
- Check pop-up blocker

**PDF looks different?**
- Open in Adobe Reader
- Try printing to PDF
- Download latest PDF reader

**Missing sections?**
- Sections only appear if data exists
- Run scan again if data seems incomplete
